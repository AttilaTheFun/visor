# Security policy

Visor lets a connected client run agents and read and write files on the
Mac that hosts it; the README's Security section describes who can connect
and what that grants.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: the repository's
Security tab → "Report a vulnerability". Do not open a public issue for
them. Include what an attacker needs (on the tailnet, knowing the
password, on the same Mac), what they gain, and the steps to reproduce.
You will get an answer, and credit in the fix if you want it.
